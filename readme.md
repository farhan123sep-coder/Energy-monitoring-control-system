Project: Energy Monitoring and Control System

Overview: IoT-based system for real-time energy monitoring and load control.

Monitoring: Measures voltage, current, power, and energy.

Controller: ESP32 processes the sensor data.

Sensor: PZEM-004T measures electrical parameters.

Control: Relay automatically controls the connected load.

Technology: Embedded C/C++, ESP32, Wi-Fi, IoT dashboard.

Output: Displays live energy parameters and load status.
